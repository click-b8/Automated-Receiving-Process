# Paperwork Gathered and Filed to the PO Folder

Part of [[QE Receiving Workflow]] · [[W01 - Parts Arrive at the Receiving Dock|← W01]] · [[W03 - Received into Quarantine in ERP|W03 →]]

**Who:** Operations (SOP Table 1, step 2)  
**Where:** Quarantine / Box PO folder

## Physical work
- Collect the packing slip, manufacturer COCs, sterilization COCs, travelers and vendor inspection reports.
- Scan or save them into the PO folder in Box: `Shipping Docs\`, `COCs\`, `Drawings\`.

## Records
- Packing slip
- Manufacturer / sterilization COCs
- Travelers, inspection reports
- PO and drawings already on file

## Automation embedded in this step
- [[Step 1 - Verify Folders and Identify Parts]]
- [[Step 2 - Match & Classify Documents]]
- [[Folder Structure]]
- [[File Access Rules]]

## Watch-outs
- Scans with no text layer push the tool onto its vision fallbacks (see [[Open Items (Master List)|Open Items]] #14, #30). Certificates bundled inside a packing-slip PDF are split out automatically; invoices are stripped; confidential Biologic travelers are never included.
