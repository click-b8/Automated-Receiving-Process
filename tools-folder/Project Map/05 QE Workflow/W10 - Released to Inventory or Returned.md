# Released to Inventory or Returned

Part of [[QE Receiving Workflow]] · [[W09 - Filed to Completed Receiving|← W09]] · end

**Who:** Operations (SOP Table 1, step 5)  
**Where:** Quarantine → inventory location / vendor

## Physical work
- Move the goods to the location the PRF disposition calls for (Raw Goods / Finished Goods) and transfer them in ERP.
- Rejected goods: return to vendor or hold under SOP 8.3.

## Records
- ERP location transfer
- PO folder documentation updated

## Automation embedded in this step
- None. This step is entirely physical or manual.

## Watch-outs
- Not part of the sequence as first described, but SOP 7.4.3 §7.10–7.11 requires it. Included so the loop closes.
