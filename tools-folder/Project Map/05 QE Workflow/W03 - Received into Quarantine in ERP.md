# Received into Quarantine in ERP

Part of [[QE Receiving Workflow]] · [[W02 - Paperwork Gathered and Filed to the PO Folder|← W02]] · [[W04 - Staged for Inspection (Monday)|W04 →]]

**Who:** Operations  
**Where:** Quarantine / ERP

## Physical work
- Count and check the goods against the packing slip.
- Sign and date the packing slip ("No Discrepancies" when clean).
- Complete the receiving list QF 7.4.3-01: receiving date, location Quarantine, qty, lot, rev, mfg/exp/ster dates.
- Receive the lot into ERP so ERP lot traceability starts (SOP 7.4.3 §8.2).

## Records
- QF 7.4.3-01 receiving list
- Signed and dated packing slip
- ERP receipt
