# Delay Playbook

What to do up front for each kind of hold-up, so the same delay doesn't repeat. The **Delays** tab of the Receiving Dashboard reads this note: each `## heading` must match a monday "Delay reason" label, and the first paragraph under it is shown as that reason's fix. Edit freely.

Delay reasons come from the monday "New inspection" board (columns **Waiting on** and **Delay reason**, added 2026-10-19). Related: [[QE Receiving Workflow]], [[Comment & Discrepancy Reasoning Reference]].

## Missing documents
Ask the vendor for the COC, inspection report / FAI and signed packing slip when the PO ships, and don't compile until Shipping Docs and COCs are complete. The receiving tool already flags a missing packing slip, receiving list, COC or FAI — treat those flags as "request now", not "note in Section 5".

## Material / finish discrepancy
Compare the drawing's material and finish callouts against the COC at receipt, and send any mismatch to Engineering Reviewer for disposition the same day rather than with the finished package.

## Dimensional out of spec
Send the disposition request to Engineering Reviewer with the Section 3 data as soon as inspection finds it, so the decision runs in parallel with compiling.

## Quantity discrepancy
Reconcile PO, packing slip and receiving list with Operations before compiling, and get the vendor's short/over-shipment confirmation in writing.

## Testing failure / root cause
Start the NCR / root-cause action immediately, record it in Section 5, and keep the unaffected parts of the PO moving.

## Vendor document error
Ask the vendor to correct or explain the document (dates, travelers, forms) at first review, and file their reply with the package.

## PRF correction
Check Section 1 (lot, qty, rev) and Section 5 against the dashboard flags and the Reasoning Reference before sending for signature.

## Signature logistics
For packages over the email size limit, send a Box link or DocuSign with the PRF attached separately from the start.

## Inspection method question
Confirm the AQL / sampling plan with Quality before inspection starts (SOP 7.4.3 Appendix A).

## Priority / expedite
Mark the PO as priority in monday when it's received so it's inspected and routed first.

## Other
Describe it in the Text column; if it repeats, add a new Delay reason label in monday and a section here.
